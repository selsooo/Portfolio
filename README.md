# 🖥️ Portfolio Interactif (OS Web) : Selsabil BIDA

Bienvenue dans le code source de mon portfolio ! Ce projet a été conçu et développé intégralement "from scratch" sous la forme d'un système d'exploitation rétro. 

L'objectif de ce format atypique est double : 
1. Proposer une expérience de navigation ludique et immersive.
2. Démontrer concrètement mes compétences techniques en développement web, indispensables pour l'intégration avancée sur des plateformes LMS.

## ✨ Fonctionnalités clés

* **Interface "OS Rétro" :** Bureau interactif avec fenêtres superposables et déplaçables (Drag & Drop).
* **Système de Modales Dynamiques :** Génération du contenu (compétences, projets) via une base de données JavaScript locale.
* **Timeline CSS sur-mesure :** Frise chronologique responsive retraçant mon parcours académique et professionnel.
* **Intégration Multimédia :** Lecteurs vidéo fluides (iframes) et visionneuse d'images (Lightbox) codée en JS natif.
* **Easter Eggs :** Quelques surprises cachées pour récompenser les visiteurs curieux !

## 🛠️ Stack Technique

Ce projet n'utilise aucun framework complexe ni constructeur de site (Wix, WordPress). Tout est codé en natif pour garantir un contrôle total sur l'interface :
* **Structure :** `HTML5` sémantique
* **Style :** `CSS3` (Flexbox, CSS Grid, animations personnalisées)
* **Logique :** `JavaScript` Vanilla (Manipulation du DOM, gestion des événements)

## 🚀 Utilisation locale

Pour explorer et tester ce projet sur votre propre machine, aucune installation complexe n'est requise :
1. Clonez ce dépôt ou téléchargez-le en fichier ZIP.
2. Décompressez le dossier sur votre ordinateur.
3. Double-cliquez simplement sur le fichier `index.html` pour l'ouvrir dans votre navigateur web (Chrome, Firefox, Safari...).

## 🎯 Plus-value en Ingénierie Pédagogique

Pourquoi coder son propre site ? En conception e-learning, la maîtrise de ces langages web fondamentaux permet de :
* S'affranchir des limites strictes des outils-auteurs classiques.
* Intervenir directement dans le code source des plateformes (ex: Moodle) pour personnaliser l'interface et résoudre des bugs d'affichage.
* Créer des intégrations sur-mesure pour enrichir l'expérience utilisateur (UX Learning) des apprenants.
